What we'll do

This workshop will be an introduction to making interactive graphics and maps in Tableau [https://www.tableau.com/](https://www.tableau.com/). We will bring spatial data stored in a shapefile together with tabular data stored in csvs, and create compelling interactive dashboards using Tableau's free offering.

What to bring

Be sure to bring laptop with Tableau Public (or Tableau Desktop, if you have access to that) installed.

* Download Tableau Public from: [https://public.tableau.com/en-us/s/download/thanks](https://public.tableau.com/en-us/s/download/thanks)
* Download the shapefiles we will use
* Download the tabular data we will use

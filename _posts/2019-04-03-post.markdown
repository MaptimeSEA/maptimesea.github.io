For this edition of Maptime, we will introduce the concept of vector tiles and use its power to create a web map. We’ll have a combination of lecture, demonstration, and hands-on experience. We'll look at the following workflow:

* Generating vector tiles with the Tippecanoe utility [https://github.com/mapbox/tippecanoe](https://github.com/mapbox/tippecanoe)
* Styling vector tiles with the Maputnik editor [https://maputnik.github.io/editor/#11.41/47.6518/-122.3225](https://maputnik.github.io/editor/#11.41/47.6518/-122.3225)
* Serving vector tiles with Tileserver-gl [https://github.com/klokantech/tileserver-gl](https://github.com/klokantech/tileserver-gl)
* Creating web maps using the Mapbox-gl-js [https://www.mapbox.com/mapbox-gl-js/api/](https://www.mapbox.com/mapbox-gl-js/api/) API

We'll have a hands-on exercise of bringing vector tiles into Maputnik editor to style them. We'll discuss the benefits of a Mapbox Studio workflow to style and create web maps.
